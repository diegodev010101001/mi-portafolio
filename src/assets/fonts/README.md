Fuentes estáticas que usa `src/app/opengraph-image.tsx` para generar la imagen de Open Graph
(el resto del sitio carga las fuentes con `next/font`).

- `SpaceGrotesk-Bold.woff`: Space Grotesk 700, subconjunto latino.
- `Inter-Medium.woff`: Inter 500, subconjunto latino.

Ambas se distribuyen bajo la SIL Open Font License 1.1 y provienen de los paquetes
`@fontsource/space-grotesk` e `@fontsource/inter`.
